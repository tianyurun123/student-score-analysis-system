
学生成绩数据化分析管理系统  
**Student Performance Digital Analysis & Management System**
-

## 项目简介
这是一套**前后端分离**的高校成绩管理平台，基于 Python + Django + Vue3 开发，实现成绩从录入、计算、管理到分析、可视化的全流程数字化解决方案。

## 核心定位
一站式解决：**成绩录入 → 计算 → 管理 → 分析 → 报告**

## 核心功能
- 多角色权限：管理员 / 教师 / 学生
- 课程、班级、教师、学生一体化管理
- Excel 批量导入成绩，自动识别字段
- 自定义评分公式，自动计算平时 / 期末 / 总成绩
- 成绩分布、班级对比、趋势分析
- 课程目标达成度自动计算与可视化
- 成绩报告生成、导出、打印

## 技术栈
**后端**
Python | Django | Django REST Framework | JWT | Redis | Celery | MySQL

**前端**
Vue3 | Element Plus | ECharts

**数据处理**
Pandas | NumPy | Excel 解析

## 项目亮点
- 前后端分离架构，易于扩展与部署
- 支持多角色权限控制，安全可靠
- 高性能：Redis 缓存 + Celery 异步任务
- 可视化数据分析图表，直观展示教学质量
- 适配高校教学管理场景，可直接部署使用

## 总结
高效、数据驱动、可配置的高校成绩全流程管理与智能分析系统。
