学生成绩数据化分析管理系统
Student Performance Digital Analysis & Management System

📖 项目简介
本项目是一套前后端分离的高校成绩管理平台，基于 Python + Django + Vue3 技术栈开发，致力于实现成绩从录入、计算、管理到分析、可视化的全流程数字化，为高校教务管理提供高效、便捷的解决方案，适配各类高校的教务场景需求。
🎯 核心定位
一站式解决高校成绩管理全流程痛点：
成绩录入 → 智能计算 → 权限管理 → 多维度分析 → 报表导出
✨ 核心功能
- 👥 多角色权限管理：区分管理员、教师、学生三级角色，精细化控制数据访问权限，保障数据安全
- 📚 基础信息管理：统一维护课程、班级、教师、学生基础信息，支持新增、编辑、删除、查询
- 📤 Excel批量导入：支持Excel批量上传成绩，自动识别字段匹配，无需手动映射，提升录入效率
- 🧮 自定义成绩计算：支持设置自定义成绩公式，自动计算平时成绩、期末成绩、总成绩，减少人工核算误差
- 📈 数据可视化分析：通过图表直观展示成绩分布、班级成绩对比、学期成绩趋势，辅助教学质量评估
- 🎯 课程目标达成度：自动计算课程目标达成度，搭配可视化图表，为教学改进提供数据支撑
- 📄 报表全流程支持：自动生成成绩报告，支持PDF/Excel格式导出、打印，满足教务归档需求
🛠️ 技术栈
🔧 后端技术

核心：Python 后端开发，Django 搭建Web框架，DRF 实现RESTful API，JWT 实现身份认证，Redis 缓存提升性能，Celery 处理异步任务，MySQL 存储核心数据。
🎨 前端技术

核心：Vue3 构建前端页面，Element Plus 提供UI组件，ECharts 实现数据可视化，打造简洁、高效的前端交互体验。
📊 数据处理

核心：通过Pandas、NumPy处理成绩数据，实现Excel文件解析、数据清洗、批量计算，提升数据处理效率。
🌟 项目亮点
- 🚀 前后端分离架构：模块化设计，前端与后端解耦，便于二次开发、功能扩展和独立部署
- 🔒 安全可靠：细粒度多角色权限控制，数据加密存储，防止未授权访问，保障教务数据安全
- ⚡ 高性能优化：Redis缓存热点数据，Celery异步处理批量导入、报表生成等耗时操作，提升系统响应速度
- 📊 直观可视化：基于ECharts实现多维度图表展示，成绩数据一目了然，辅助教务决策
- 🎓 场景适配性强：完全贴合高校教务实际业务流程，无需大量修改，可直接部署使用
🚀 安装与运行
前提：已安装 Python 3.8+、Node.js 14+、MySQL 8.0+、Redis 6.0+
1️⃣ 后端启动（Django服务）
# 克隆项目（若需）
git clone https://github.com/xxx/student-performance-system.git
cd student-performance-system

# 进入后端目录
cd backend

# 安装依赖
pip install -r requirements.txt

# 配置数据库（修改settings.py中的数据库连接信息）
# 执行数据库迁移
python manage.py makemigrations
python manage.py migrate

# 创建超级管理员（用于后台登录）
python manage.py createsuperuser

# 启动后端服务（默认端口8000）
python manage.py runserver
2️⃣ 前端启动（Vue3服务）
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 启动前端开发服务（默认端口8080）
npm run serve
3️⃣ 访问系统
- 后端管理地址：http://127.0.0.1:8000/admin（使用超级管理员账号登录）
- 前端页面地址：http://127.0.0.1:8080（学生/教师/管理员登录）
